# LF2 Twitch Lite

Panasonic TH-43LF2Y向けの軽量Twitchランチャーです。

## v0.6 — チャット付き視聴（試験表示）

「チャットと一緒に見る」をオンにすると、公式の映像プレイヤーと公式チャットを並べて表示します。初期状態は従来の映像のみです。選んだ表示方法はブラウザ内に保存されます。

- テレビなどの横長画面では、左に映像、右にチャットを表示します。
- 「全体を全画面」で、映像とチャットを含む視聴画面を全画面表示します。映像プレイヤー内の全画面ボタンは映像だけが対象です。
- 「チャットを隠す」でチャットの読み込みを終了し、映像の領域を広げます。再表示時にチャットを読み込み直します。
- 「映像のみで開く」で、従来のプレイヤー直接表示へ移動できます。
- PCによる中継、独自サーバー、アプリ独自の認証設定は不要です。

**TH-43LF2Y実機での映像・チャットの同時表示、更新、リモコン操作は未確認です。** Twitch側の画面がテレビのブラウザで読み込めるかは、実機で確認してください。自動再生が止まる場合はプレイヤーの再生ボタンを押してください。チャットへの投稿はTwitch側のログインやチャンネルの条件に従います。

チャット付き視聴はライブ配信のチャンネルが対象です。録画のチャット再生は対象外です。

### 実装済み

- お気に入りストリーマーの追加・削除
- お気に入りの LIVE / OFFLINE 表示
- LIVE中の配信者を先頭へ並べ替え
- 起動時・約5分ごとのLIVE状態更新
- 手動の「LIVE更新」
- Twitch URL / チャンネル名から直接再生
- 前回見たチャンネルを起動直後に1ボタンで再生
- 最近見たチャンネルを最大10件保存
- お気に入り・履歴をテレビ側 localStorage に保存
- 設定のJSON書き出し・読み込み
- チャット付き視聴の選択と保存（従来のバックアップも読み込み可能）
- PCによる動画中継なし
- TH-43LF2Yのリモコンで扱いやすい大きめUI

## LIVE判定

v0.5では軽量性を優先し、DecAPI の Twitch uptime エンドポイントを使って LIVE / OFFLINE のみ判定しています。

- Twitch Client ID / OAuth設定は不要
- APIキーや秘密情報をPublicリポジトリに置かない
- お気に入り一覧そのものはGitHubには保存しない
- LIVE状態はDecAPI側で最大約5分キャッシュされるため、切り替わり直後は表示に遅延する場合があります
- DecAPIが利用できない場合は状態を「不明」として扱い、視聴機能自体はそのまま使えます

## Twitch再生

映像のみの表示では、以下の軽量プレイヤーを直接開きます。

https://player.twitch.tv/?channel=<channel>&parent=twitch.tv&player=popout&autoplay=true&muted=false

チャット付き表示では `watch.html?channel=<channel>` から、公式の映像とチャットを別々のiframeとして読み込みます。埋め込み元を指定する `parent` はページの実際のホスト名を使用します。GitHub Pagesの公開先では `nuju.github.io` です。HTTPSが必要です。

公式仕様:
- [Embedding Chat](https://dev.twitch.tv/docs/embed/chat/)
- [Embedding Video and Clips](https://dev.twitch.tv/docs/embed/video-and-clips/)
- [Embedding Twitch](https://dev.twitch.tv/docs/embed/)

表示確認は、チャット付きで配信者を選び、映像の再生・新しいチャットの到着・「全体を全画面」・「一覧へ戻る」の順で行ってください。

## 方針

テレビ上での軽さを優先します。実機で使って必要になった機能だけ追加します。

保留案:
- 配信サムネイル
- 配信タイトル
- ゲームカテゴリ
- 配信開始時刻
- スマホからのお気に入り編集
- Twitch公式APIを使った高度な連携
